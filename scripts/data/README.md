# Opening-film source data

natural-earth-countries.geojson contains geometry and country names from Natural Earth's public-domain 1:110m country dataset, retrieved for the geographic opening. The original source is:

https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_admin_0_countries.geojson

The geometry is bundled so rendering does not require network access. The map expresses the company's Indonesian origin and Asian ambition, not current operating coverage.

Inter-Variable.ttf comes from the public SECHA Studio+ source used in this task. Its SIL Open Font License is included at ../../assets/fonts/OFL.txt. It is a renderer dependency, not a browser runtime asset.
